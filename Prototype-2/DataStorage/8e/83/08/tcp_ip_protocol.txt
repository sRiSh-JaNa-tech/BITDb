The TCP/IP protocol suite is the conceptual model and set of protocols used on the Internet.
It consists of four layers: Network Access, Internet, Transport, and Application.
Transmission Control Protocol (TCP) provides reliable, ordered, and error-checked delivery of octets.
Internet Protocol (IP) is responsible for addressing and routing packets across network boundaries.
IPv4 addresses are 32-bit numbers, typically represented in dotted-decimal notation.
IPv6 addresses are 128-bit numbers, introduced to resolve IPv4 address exhaustion issues.
User Datagram Protocol (UDP) is a connectionless, lightweight protocol with minimal overhead.
TCP establishes connections using a three-way handshake: SYN, SYN-ACK, and ACK.
TCP terminates connections using a four-way handshake involving FIN and ACK packets.
Flow control prevents a fast sender from overwhelming a slow receiver using sliding windows.
Congestion control prevents network collapse by dynamically adjusting transmission rates.
TCP congestion window (cwnd) size is managed by slow start, congestion avoidance, fast retransmit.
Maximum Transmission Unit (MTU) is the size of the largest protocol data unit that can be passed.
Fragmentation occurs when an IP packet is split into smaller units to fit MTU limits.
Subnetting divides a larger network into smaller, manageable subnetwork segments.
Classless Inter-Domain Routing (CIDR) allocates IP addresses and routes packets flexibly.
Address Resolution Protocol (ARP) maps IP addresses to physical MAC addresses on local links.
Domain Name System (DNS) translates human-readable domain names into numerical IP addresses.
Hypertext Transfer Protocol (HTTP) is the application protocol used for distributed information.
Secure Sockets Layer (SSL) and Transport Layer Security (TLS) encrypt TCP communications.
Ports identify specific applications or services running on a host computer network.
Well-known ports range from 0 to 1023, registered for standard services like HTTP (80).
Network Address Translation (NAT) maps private local IPs to a single public IP address.
Ping uses ICMP echo requests and replies to test host reachability over networks.
Traceroute records the path and transit delays of packets across an IP network.
