OSPF is a link-state routing protocol for internal networks.
It operates within a single autonomous system domain boundary.
OSPF uses areas to structure networks hierarchically and scale.
Area 0 is the backbone area, connecting all other areas.
Routers within an area maintain identical link-state databases.
Link State Advertisements (LSAs) share topology details with neighbors.
OSPF routers establish adjacencies using periodic Hello packets.
Hello packets check link status and elect designated routers.
Designated Router (DR) reduces routing update exchanges on segments.
Backup Designated Router (BDR) assumes DR role if it fails.
OSPF metric is cost, inversely proportional to interface bandwidth.
Dijkstra's shortest path first algorithm calculates optimal routes.
Shortest path tree is built with local router as root.
OSPF converges quickly when network topology changes occur.
Triggered updates flood LSAs immediately when link states change.
OSPF supports Classless Inter-Domain Routing (CIDR) subnetting.
OSPFv2 is used for IPv4; OSPFv3 supports IPv6 routing.
OSPF routing tables are updated dynamically based on tree calculations.
Equal-cost multi-path (ECMP) load balances traffic across paths.
LSA aging deletes stale routing records after 3600 seconds.
Database Description packets sync databases during initial adjacency.
Link State Requests (LSR) ask neighbors for updated LSAs.
Link State Updates (LSU) deliver requested LSAs to neighbors.
OSPF is widely used in enterprise networks due to reliability.
Configuring OSPF requires understanding area borders and summarization.
