BGP is the routing protocol of the global Internet.
It is a path-vector protocol managing Autonomous System paths.
Internal BGP (iBGP) routes traffic within a single AS.
External BGP (eBGP) routes traffic between distinct AS nodes.
BGP peers establish TCP connections on port 179 for safety.
They exchange complete routing tables during initial setup.
Incremental updates are sent only when routes change thereafter.
BGP routing choices are based on policies and attributes.
AS-Path attribute lists Autonomous Systems a route passes through.
Shortest AS-Path is preferred to minimize inter-domain hops.
Next-Hop attribute specifies the IP address of next router.
Local Preference attribute prioritizes exit paths within an AS.
Multi-Exit Discriminator (MED) suggests preferred entry paths to neighbors.
BGP path selection algorithm runs a strict tie-breaker list.
BGP is highly stable, preventing routing loops using AS-Path.
If local AS is in AS-Path, packet route is discarded.
Route reflectors reduce full-mesh iBGP connection requirements.
BGP communities tag routes to apply policies across groups.
CIDR block aggregation reduces global routing table sizes.
Global routing tables contain over one million route prefixes.
BGP hijacking occurs when wrong routes are advertised maliciously.
RPKI secures BGP by validating route origin advertisements.
Flapping routes are temporarily suppressed using BGP dampening.
BGP allows ISPs to negotiate complex transit agreements.
Without BGP, the global internet routing would fail to function.
