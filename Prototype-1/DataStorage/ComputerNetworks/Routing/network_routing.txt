Routing is the process of selecting paths in a network to send network traffic.
Routers are network hardware devices that forward data packets between computer networks.
Routing tables store information about network topology, destinations, and next-hop paths.
Static routing involves manually configuring routing table entries in network devices.
Dynamic routing uses protocols to discover destinations and share topology changes automatically.
Routing protocols are divided into Interior Gateway Protocols (IGP) and Exterior Gateway Protocols.
Distance-vector protocols determine routes based on distance vectors (hop counts) shared with neighbors.
Routing Information Protocol (RIP) is a classic distance-vector protocol using hop counts.
Link-state protocols build complete network maps by flooding link state advertisements.
Open Shortest Path First (OSPF) is a link-state routing protocol based on Dijkstra's algorithm.
Dijkstra's algorithm calculates the shortest path from a source node to all other nodes.
Border Gateway Protocol (BGP) is the standardized exterior gateway protocol for the Internet.
BGP is a path-vector protocol that manages routing decisions based on paths and policies.
Autonomous Systems (AS) are collections of connected IP routing prefixes controlled by one entity.
Hot-potato routing forwards traffic to the closest exit point of the autonomous system.
Cold-potato routing keeps traffic within the autonomous system as long as possible.
Routing loops occur when packets are forwarded continuously in a closed circle.
Split horizon prevents routing loops by not advertising routes back to their source interfaces.
Route poisoning prevents loops by advertising failed routes with an infinite metric distance.
Load balancing distributes traffic across multiple paths to optimize network utilization.
Anycast routing forwards packets to the nearest node among a group of identical receivers.
Multicast routing distributes data packets to a group of interested destination hosts.
Unicast routing sends data packets to a single, specific destination host on the network.
Default route is the path taken when no specific destination matches the routing table.
Software-Defined Networking (SDN) separates the control plane from the data forwarding plane.
