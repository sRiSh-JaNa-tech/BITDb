Page replacement algorithms are critical for virtual memory efficiency.
The goal is to minimize the total number of page faults.
FIFO replacement is simple but can suffer from Belady's Anomaly.
Belady's anomaly means page faults increase as frames are added.
Optimal algorithm (OPT) has lowest page fault rate of all.
OPT requires knowing future page references, making it impossible.
Least Recently Used (LRU) associates page access history with frames.
It replaces the page that has not been used for longest time.
Implementing exact LRU requires hardware counters or stack tracking.
Because exact LRU is expensive, approximation algorithms are used.
Reference bit is set by hardware whenever a page is accessed.
Second-chance (clock) algorithm uses reference bit in circular list.
It gives pages a second chance if reference bit is set.
Enhanced second-chance considers reference and modification dirty bits.
Least Frequently Used (LFU) replaces page with smallest count.
Most Frequently Used (MFU) assumes low counts mean newly loaded.
Page buffering maintains a pool of free frames for quick allocation.
Victim pages are written to disk in background before reuse.
Raw disk I/O bypasses OS caching for databases like Oracle.
Swap space management reserves disk partitions for page swapping.
Locality of reference ensures processes access memory clustered.
Spatial locality means accessing memory close to current address.
Temporal locality means accessing same memory repeatedly in time.
Efficient page replacement keeps systems responsive under heavy load.
Modern operating systems combine multiple page replacement strategies.
