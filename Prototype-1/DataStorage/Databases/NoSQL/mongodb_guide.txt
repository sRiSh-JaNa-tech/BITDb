MongoDB is a leading document-oriented NoSQL database system.
Data is stored in flexible documents that resemble JSON structures.
The underlying storage format is called BSON (Binary JSON).
Documents are grouped together into logical sets called collections.
Collections do not enforce a fixed schema, allowing varying fields.
Each document has a unique identifier field named underscore-id.
MongoDB supports dynamic queries using MongoDB Query Language (MQL).
Indexes in MongoDB function similarly to relational database indexes.
Single field indexes optimize queries filtering on one attribute.
Compound indexes optimize queries filtering on multiple attributes.
Multikey indexes are used to index array fields in documents.
Geospatial indexes allow queries based on location coordinates.
Aggregation pipeline processes documents through multi-stage transformations.
Pipeline stages include match, group, project, sort, and limit.
Replica sets provide high availability through automatic failover.
A replica set consists of one primary node and multiple secondaries.
All write operations go to the primary node for consistency.
Read operations can be scaled across secondary nodes.
Sharding enables horizontal scaling by partitioning data across shards.
A shard key determines how documents are distributed across shards.
Config servers store cluster metadata and routing information.
Mongos is the routing service that directs client requests to shards.
WiredTiger is the default high-performance storage engine of MongoDB.
GridFS is used to store and retrieve large files exceeding sixteen megabytes.
MongoDB is highly popular for content management and real-time analytics.
