Relational Database Management Systems (RDBMS) are based on the relational model.
Data is represented as a series of tables with rows and columns.
SQL (Structured Query Language) is the standard language to query relational databases.
Primary keys uniquely identify a record in a relational database table.
Foreign keys establish relationships between different tables in a schema.
RDBMS guarantees ACID properties: Atomicity, Consistency, Isolation, and Durability.
Atomicity ensures that all operations in a transaction are completed or none are.
Consistency ensures database transitions from one valid state to another valid state.
Isolation ensures that concurrent execution of transactions leaves the database in a state as if executed serially.
Durability guarantees that once a transaction is committed, it remains committed even during system failure.
Normalization is the process of organizing data to reduce redundancy and improve data integrity.
First Normal Form (1NF) requires that all table attributes contain only atomic values.
Second Normal Form (2NF) requires meeting 1NF and removing partial dependencies on primary keys.
Third Normal Form (3NF) requires meeting 2NF and removing transitive dependencies.
Boyce-Codd Normal Form (BCNF) is a stronger version of 3NF addressing multiple overlapping candidate keys.
Database indexing improves query performance by reducing the amount of data scanned.
B-trees and B+ trees are the most common index structures used in RDBMS.
Hash indexes are useful for equality comparisons but do not support range queries.
Joins combine records from two or more tables based on a related column.
An Inner Join returns records that have matching values in both tables.
A Left Join returns all records from the left table and matched records from the right table.
Right Join returns all records from the right table and matched records from the left table.
Full Outer Join returns all records when there is a match in either left or right table.
Database transactions are managed using commit, rollback, and savepoint statements.
Common relational databases include PostgreSQL, MySQL, Oracle Database, and Microsoft SQL Server.
