SQL stands for Structured Query Language, the standard for RDBMS.
SQL statements are divided into DDL, DML, DCL, and TCL.
Data Definition Language (DDL) defines schemas: CREATE, ALTER, DROP.
Data Manipulation Language (DML) manages data: SELECT, INSERT, UPDATE, DELETE.
Data Control Language (DCL) manages privileges: GRANT, REVOKE.
Transaction Control Language (TCL) manages transactions: COMMIT, ROLLBACK.
The SELECT clause specifies which columns to retrieve from tables.
The FROM clause specifies the source tables for the query.
The WHERE clause filters rows based on conditional expressions.
The GROUP BY clause aggregates rows sharing common column values.
The HAVING clause filters aggregated groups after the GROUP BY is applied.
The ORDER BY clause sorts query results in ascending or descending order.
Aggregate functions include SUM, AVG, COUNT, MIN, and MAX.
Window functions perform calculations across related table rows (e.g., ROW_NUMBER).
The OVER clause defines the partitioning and ordering for window functions.
Common Table Expressions (CTEs) define temporary result sets using WITH.
Subqueries are nested queries inside another SQL statement.
Correlated subqueries refer to columns from the outer query context.
UNION combines the distinct results of two or more SELECT queries.
UNION ALL combines results including duplicates for faster execution.
LIKE operator uses wildcards (%) to match character string patterns.
COALESCE returns the first non-null expression from a list of arguments.
CASE expression provides conditional logic within SQL SELECT statements.
Transactions begin implicitly or explicitly with BEGIN TRANSACTION.
SQL syntax is standardized by ANSI but has vendor-specific extensions.
