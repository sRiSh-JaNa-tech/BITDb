Convolutional Neural Networks (CNNs) are deep learning architectures designed for spatial data processing.
CNNs are widely used in computer vision, image classification, segmentation, and object detection.
A convolution layer applies learnable filters (kernels) to input features to produce feature maps.
Kernels slide across input channels to perform element-wise multiplications and additions.
Stride determines the step size the kernel moves when scanning the input image or feature map.
Padding adds pixels (usually zeros) to input borders to control the spatial size of output maps.
Pooling layers reduce the spatial dimensions of feature maps, lowering computational complexity.
Max pooling extracts the maximum value within a sliding window, preserving key features.
Average pooling computes the average value within a sliding window to downsample representations.
Receptive field defines the local region in the input space that influences a specific feature.
Feature maps capture hierarchically complex features, from edge detectors to object parts.
Fully connected layers map flattened convolutional features to final output prediction classes.
AlexNet won the ImageNet competition in 2012, accelerating deep learning adoption.
VGG architectures utilize stacks of small 3x3 convolutional filters to build very deep networks.
Residual Networks (ResNet) introduced skip connections (shortcuts) to resolve vanishing gradients.
Skip connections allow identity mappings to bypass one or more layers, simplifying optimization.
1x1 convolutions are used for dimensionality reduction and channel-wise pooling.
Inception blocks apply convolutions of multiple kernel sizes in parallel within the same layer.
Dilated convolutions expand the kernel receptive field without adding parameter size.
Transposed convolutions (deconvolutions) are used to upsample feature maps in generative models.
Data augmentation increases training diversity by applying rotations, flips, and crops to images.
Transfer learning utilizes weights pre-trained on large datasets like ImageNet for new tasks.
Object detection frameworks like YOLO and Faster R-CNN locate and classify objects in images.
Semantic segmentation assigns a class label to every individual pixel in an image.
U-Net is a popular encoder-decoder CNN architecture designed for biomedical image segmentation.
