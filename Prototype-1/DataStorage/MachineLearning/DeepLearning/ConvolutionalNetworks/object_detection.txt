Object detection identifies and locates objects within images.
It outputs bounding box coordinates and classification labels.
Traditional methods used sliding windows and hand-crafted features.
Deep learning revolutionized detection accuracy and processing speed.
Two-stage detectors divide detection into proposal and classification.
Region-based CNN (R-CNN) proposed boxes, then classified each.
Fast R-CNN shared convolutional feature extraction across proposals.
Faster R-CNN introduced Region Proposal Network (RPN) inside model.
RPN predicts region proposals directly from convolutional feature maps.
One-stage detectors predict bounding boxes and classes in one pass.
You Only Look Once (YOLO) treats detection as regression problem.
YOLO divides image into grid, predicting boxes and probabilities.
Single Shot MultiBox Detector (SSD) uses multi-scale feature maps.
One-stage detectors are generally faster, suitable for real-time.
Two-stage detectors are generally more accurate for small objects.
Anchor boxes serve as reference boxes of varying shapes and scales.
Intersection over Union (IoU) measures overlap between box predictions.
Non-Maximum Suppression (NMS) removes redundant overlapping box predictions.
Focal Loss resolves extreme foreground-background class imbalance in one-stage.
Feature Pyramid Networks (FPN) combine low-level and high-level features.
This improves detection performance for objects of varying sizes.
Backbone networks (like ResNet) extract features from input images.
Neck networks (like PANet) mix and refine extracted features.
Head networks predict final bounding boxes and class scores.
Object detection is critical for autonomous driving and surveillance.
