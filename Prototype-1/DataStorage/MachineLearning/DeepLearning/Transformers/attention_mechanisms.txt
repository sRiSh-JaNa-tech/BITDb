Attention mechanisms allow models to focus on specific parts.
They dynamically weight the importance of different input features.
Bahdanau attention was introduced for machine translation in RNNs.
It computes alignment scores between encoder states and decoder.
Luong attention simplified this, using dot-product alignment calculations.
Self-attention relates different positions of a single sequence.
Attention formula uses Query, Key, and Value matrices.
Query represents target token; Key represents search tokens context.
Value represents actual content to retrieve based on alignment.
Scaled dot-product attention divides dot products by scaling factor.
Scaling by square root of key dimension prevents gradient saturation.
Softmax converts scaled dot products to attention weights probabilities.
Multi-head attention projects Queries, Keys, Values into subspaces.
This allows learning different types of contextual relationship features.
Causal masking prevents attention from looking at future tokens.
It is implemented by setting future attention weights to negative infinity.
Cross-attention connects decoder Queries with encoder Keys and Values.
Local attention restricts token context to neighboring sequence windows.
Sparse attention models reduce quadratic complexity of full attention.
FlashAttention accelerates computation using hardware-aware SRAM tiling.
This reduces memory reads and writes during training steps.
Attention weights can be visualized to interpret model logic.
They show how nouns relate to pronouns across long sentences.
Attention is the key innovation behind state-of-the-art LLMs.
It has expanded from text to vision and audio domains.
