Transformers are sequence-to-sequence deep learning models based entirely on attention mechanisms.
The Transformer architecture was introduced in the seminal 2017 paper 'Attention Is All You Need'.
Unlike Recurrent Neural Networks (RNNs), Transformers process sequence tokens in parallel.
Self-attention allows tokens to dynamically relate to all other tokens in a sequence.
The attention mechanism is computed using Query, Key, and Value vectors derived from inputs.
Scaled Dot-Product Attention calculates attention scores by multiplying Query and Key matrices.
Attention scores are scaled by the square root of key dimensions to prevent small gradients.
Softmax is applied to attention scores to create a probability distribution over sequence tokens.
Multi-head attention applies multiple self-attention mechanisms in parallel to capture diverse contexts.
Positional encoding is added to input embeddings to preserve token order information.
Sinusoidal functions of different frequencies are commonly used for positional encodings.
The Encoder stack consists of identical layers containing multi-head attention and feedforward sublayers.
The Decoder stack uses masked multi-head attention to prevent looking at future tokens during generation.
Residual connections and layer normalization are applied around each transformer sublayer.
BERT (Bidirectional Encoder Representations from Transformers) is pre-trained using masked language modeling.
GPT (Generative Pre-trained Transformer) is a decoder-only model trained for autoregressive prediction.
T5 (Text-to-Text Transfer Transformer) casts all NLP tasks into a unified text-to-text format.
Layer normalization in Transformers is typically applied before (Pre-LN) or after (Post-LN) sublayers.
Attention maps visualize the relative importance tokens place on each other during inference.
Self-attention computation scales quadratically with sequence length, posing resource challenges.
Linear attention models attempt to reduce attention complexity to linear time and space.
Fine-tuning adapts a pre-trained transformer model to a specific downstream task using labeled data.
Prompt engineering optimizes input sequences to guide generative transformer responses effectively.
Reinforcement Learning from Human Feedback (RLHF) aligns transformer generation with human preferences.
Large Language Models (LLMs) are scaled-up transformers containing billions of parameter weights.
