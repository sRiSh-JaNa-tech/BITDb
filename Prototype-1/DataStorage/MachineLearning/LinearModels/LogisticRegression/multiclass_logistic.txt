Multiclass logistic regression handles three or more classes.
It is also known as multinomial logistic regression.
Softmax regression is the standard generalization for multiclass.
Softmax function generalizes logistic sigmoid to multiple outputs.
It exponentiates raw scores and normalizes to sum to one.
This produces a probability distribution over all target classes.
Cross-entropy loss measures difference between target and distribution.
One-vs-Rest (OvR) trains binary classifier for each class.
The class with highest predicted probability is chosen.
OvR is simple and parallelizable but lacks joint probability.
One-vs-One (OvO) trains classifier for every class pair.
For K classes, OvO requires K times K-1 over two models.
Classification is decided by majority vote among pair models.
OvO is computationally expensive for large numbers of classes.
Multinomial logistic regression optimizes all classes jointly.
It uses a single objective function, sharing parameters.
Coefficients represent log-odds relative to a baseline class.
Gradient computation updates parameter matrices across all classes.
Regularization is applied to all parameter vectors simultaneously.
L2 regularization prevents individual class weights from exploding.
Evaluation uses confusion matrices to track class-specific errors.
Micro-averaging calculates metrics globally across all samples.
Macro-averaging calculates metrics for each class, then averages.
Weighted-averaging weights class metrics by their sample support.
Multiclass models are essential for handwriting and text classification.
