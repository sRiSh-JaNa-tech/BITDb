Regression metrics evaluate how well models predict values.
Mean Absolute Error (MAE) averages absolute residual differences.
MAE is robust to outliers, weighting all errors linearly.
Mean Squared Error (MSE) averages squared residual differences.
MSE penalizes larger errors heavily, sensitive to outliers.
Root Mean Squared Error (RMSE) is square root of MSE.
RMSE is in the same units as the target variable.
Mean Absolute Percentage Error (MAPE) measures relative percentage errors.
MAPE is useful but undefined when target values are zero.
R-squared (coefficient of determination) measures fit goodness.
It compares model residuals against simple mean baseline residuals.
An R-squared of one indicates perfect model predictions.
An R-squared of zero indicates model performs like mean baseline.
Negative R-squared indicates model is worse than mean baseline.
Adjusted R-squared penalizes adding uninformative predictor variables.
This prevents artificially inflating R-squared with noise columns.
Residual plots help diagnose model assumption violations visually.
Patterns in residuals indicate non-linearity or heteroscedasticity.
Q-Q plots check if residuals follow a normal distribution.
Scale-location plot checks homoscedasticity across fitted values.
Cook's distance identifies highly influential outlier data points.
Durbin-Watson statistic checks for autocorrelation in residual terms.
Multi-fold cross-validation computes metrics across validation sets.
This ensures metrics reflect generalization instead of training fit.
Selecting correct metrics depends on application business objectives.
