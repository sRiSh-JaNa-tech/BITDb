Linear regression is a linear approach for modeling the relationship between a scalar response and variables.
Simple linear regression models the relationship between a single independent variable and dependent variable.
Multiple linear regression models relationships involving two or more independent predictor variables.
The linear regression equation is typically written as Y equals beta-zero plus beta-one times X plus error.
Beta-zero represents the intercept parameter, showing the expected value of Y when X is zero.
Beta-one represents the slope parameter, indicating the change in Y per unit change in X.
Ordinary Least Squares (OLS) is the standard method to estimate parameters by minimizing squared residuals.
Residuals are the differences between observed values and values predicted by the regression line.
The Gauss-Markov theorem states that under certain conditions, OLS estimators are BLUE (Best Linear Unbiased Estimators).
Key assumptions include linearity, independence of errors, homoscedasticity, and normality of errors.
Homoscedasticity means the variance of residual error terms remains constant across all predictor values.
Multicollinearity occurs when independent variables are highly correlated with each other.
Variance Inflation Factor (VIF) is used to detect and measure multicollinearity severity.
R-squared measures the proportion of variance in the dependent variable explained by predictors.
Adjusted R-squared adjusts the metric based on the number of predictor variables in the model.
L1 regularization (Lasso regression) adds absolute parameter values to loss, enabling feature selection.
L2 regularization (Ridge regression) adds squared parameter values to loss, preventing extreme weights.
Elastic Net regression combines L1 and L2 regularization penalties into a single loss function.
Gradient Descent can be used to iteratively find parameters that minimize the mean squared error.
Feature scaling helps gradient descent converge faster by putting features on similar scales.
Outliers can significantly skew linear regression parameters due to the squaring of residuals.
Polynomial regression models non-linear relationships by raising independent variables to powers.
Interaction terms model situations where the effect of one predictor depends on another predictor.
Cross-validation is used to evaluate linear regression generalization performance on unseen test data.
Linear regression is highly interpretable, making it a foundational tool in statistical analysis.
