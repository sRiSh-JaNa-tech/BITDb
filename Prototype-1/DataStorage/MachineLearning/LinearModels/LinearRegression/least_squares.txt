Least squares is the standard method for parameter estimation.
It minimizes the sum of squared differences between predictions.
Residual Sum of Squares (RSS) is the objective function minimized.
Analytical solution is computed using the normal equation formula.
Normal equation is X-transpose X inverse times X-transpose Y.
Computing this requires X-transpose X to be invertible.
Invertibility fails if independent variables are perfectly collinear.
Pseudo-inverse (Moore-Penrose) handles non-invertible matrix cases.
Least squares estimators are unbiased if assumptions are met.
Unbiased means expected parameter values equal true population parameters.
Gauss-Markov theorem states OLS has the minimum variance.
Minimum variance makes OLS the best linear unbiased estimator.
However, OLS is highly sensitive to outlier data points.
Outliers pull the regression line, inflating prediction errors elsewhere.
Robust regression methods (like Huber loss) mitigate outlier impact.
Huber loss is quadratic for small errors and linear for large.
Generalized Least Squares (GLS) handles non-constant error variance.
Weighted Least Squares (WLS) weights samples by inverse variance.
Recursive Least Squares (RLS) updates parameters dynamically as data arrives.
Orthogonal Distance Regression minimizes perpendicular distances to the line.
This is used when independent variables also contain measurement errors.
Least squares formulation is equivalent to maximum likelihood estimation.
This equivalence holds when error terms are normally distributed.
It is a fundamental algorithm in optimization and statistics.
Understanding least squares is key to learning linear systems.
