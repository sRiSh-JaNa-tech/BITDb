Support Vector Machines (SVMs) are supervised learning models used for classification and regression.
SVMs search for the optimal hyperplane that separates classes with the maximum possible margin.
The margin is the distance between the separating hyperplane and the closest training data points.
Support vectors are the training data points that lie closest to the decision boundary.
If these support vectors were removed, the position of the separating hyperplane would change.
Linear SVMs assume that the classes are linearly separable in the input feature space.
Soft margin classification allows some misclassifications to handle noisy or overlapping data.
The C hyperparameter controls the trade-off between maximizing margin and minimizing training errors.
A small C value creates a wider margin but permits more misclassifications during training.
A large C value aims for a narrow margin with fewer classification mistakes on training points.
Kernel trick maps low-dimensional inputs into higher-dimensional spaces where they become separable.
Kernels compute similarity between data points in high dimensions without explicit transformation.
Linear kernel is used when data is already linearly separable in its original space.
Polynomial kernel computes relation representations using polynomial combinations of features.
Radial Basis Function (RBF) kernel is a popular non-linear kernel based on distance metrics.
The gamma hyperparameter in RBF controls the influence radius of individual training points.
A small gamma value means far-reaching influence, creating a smoother decision boundary.
A large gamma value means close-range influence, leading to more complex decision boundaries.
SVMs are effective in high-dimensional spaces, even when dimensions exceed sample sizes.
They are memory efficient because they only use support vectors in the decision function.
SVMs are sensitive to feature scaling, requiring normalization before model training.
They do not directly provide probability estimates, requiring Platt scaling approximation.
Hinge loss is the optimization loss function used by SVMs for classification tasks.
Multi-class SVM classification is achieved using One-vs-One or One-vs-All voting schemes.
SVMs are widely applied in text categorization, image classification, and bioinformatics.
