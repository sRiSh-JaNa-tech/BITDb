Kernel functions enable SVMs to handle non-linear data.
They compute inner products in high-dimensional feature spaces.
This bypasses explicit coordinate mapping, saving computation.
Mercer's theorem defines conditions for valid kernel functions.
A valid kernel must be symmetric and positive semi-definite.
Linear kernel performs simple dot product in input space.
It is fast and effective for high-dimensional text datasets.
Polynomial kernel computes dot products raised to power d.
It models interactions between features up to degree d.
Radial Basis Function (RBF) is most widely used kernel.
RBF kernel represents similarity as exponentially decaying distance.
It implicitly maps inputs to infinite-dimensional feature space.
Sigmoid kernel is inspired by neural network activation functions.
Cosine similarity kernel measures angular similarity between vectors.
String kernels compare text sequences based on substring matches.
Graph kernels compute similarity between structured graph data.
Choosing the right kernel is critical to model generalization.
RBF is a safe default but requires tuning parameters.
Grid search with cross-validation is used for kernel selection.
Custom kernels can be designed for domain-specific structures.
Overfitting can occur if kernel maps to too complex space.
Kernel matrix stores pairwise similarities for all samples.
Computing kernel matrix scales quadratically with dataset size.
This restricts kernel SVMs to medium-sized training datasets.
Kernel methods remain a powerful paradigm in machine learning.
